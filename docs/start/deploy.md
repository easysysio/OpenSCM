# Deploy Options

OpenSCM is available in two forms. Both are free — pick what fits your situation.

<div class="deploy-grid deploy-grid--full" markdown>

<div class="deploy-card deploy-card--featured" markdown>

### :material-cloud: Cloud

**Hosted at [app.openscm.io](https://app.openscm.io)**

The fastest way to get started. Create an account and have your first agent
reporting in under five minutes — no server to install or maintain.

| | |
|---|---|
| **Systems** | Up to 25 (free) |
| **Setup time** | ~5 minutes |
| **Maintenance** | Managed for you |
| **Data location** | OpenSCM infrastructure |
| **Cost** | Free |

#### What you get

- :material-check-circle:{ .green } Full OpenSCM dashboard — policies, tests, reports, scheduler
- :material-check-circle:{ .green } Multi-user support with role-based access
- :material-check-circle:{ .green } Email notifications and support tickets
- :material-check-circle:{ .green } Always running the latest release

#### How to start

1. Go to **[app.openscm.io](https://app.openscm.io)** and create a free account
2. Copy your server URL and organization slug from the setup page
3. Install the agent on your systems — same packages as self-hosted

[Create Free Account :octicons-arrow-right-24:](https://app.openscm.io){ .md-button .md-button--primary }

</div>

### :material-server: Self-Hosted

**Run on your own infrastructure**

Install the server anywhere — a VM, bare metal, or Docker. Your compliance
data never leaves your network.

| | |
|---|---|
| **Systems** | Unlimited |
| **Setup time** | ~10 minutes |
| **Maintenance** | You manage it |
| **Data location** | Your infrastructure |
| **Cost** | Free |

#### What you get

- :material-check-circle:{ .green } Unlimited systems, users, policies, and reports
- :material-check-circle:{ .green } Complete data sovereignty — nothing leaves your network
- :material-check-circle:{ .green } Linux, macOS, Windows, FreeBSD, Docker
- :material-check-circle:{ .green } x86\_64, ARM64, ARMv7, PowerPC
- :material-check-circle:{ .green } Open source — inspect, contribute, fork

#### How to start

1. [Download](downloads.md) the server package for your platform
2. Follow the [Installation guide](installation.md)
3. Install agents on your systems

[Installation Guide :octicons-arrow-right-24:](installation.md){ .md-button .md-button--primary }
