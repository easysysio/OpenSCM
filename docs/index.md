    ---
    Define and enforce security policies aligned with **CIS, NIST, and SOC2** 
    frameworks across your entire infrastructure.

-   :material-devices:{ .lg .middle } __Cross-Platform & Multi-Arch__
    ---
    Run anywhere. Agent supports **Linux, Windows, macOS, and FreeBSD** across
    **x86, ARM, ARMv7, and PowerPC** architectures.

-   :material-database:{ .lg .middle } __Zero-Config Database__
    ---
    Ships with embedded **SQLite** — no database server to install, configure,
    or maintain. Works out of the box for any fleet size.

-   :material-memory:{ .lg .middle } __Memory Safe Platform__
    ---
    Engineered with **Rust** to eliminate memory-related vulnerabilities, 
    providing a rock-solid foundation for your security tooling.

-   :material-shield-account:{ .lg .middle } __Privacy First__
    ---
    Complete data sovereignty. Agents share **only PASS, FAIL, or NA** 
    with the server — no raw system data, no telemetry, nothing else 
    ever leaves your network.

-   :material-file-document-check:{ .lg .middle } __Audit-Ready Reporting__
    ---
    Generate and archive compliance reports as formal **PDF evidence** 
    with one click. Simplify your next security audit.

-   :material-open-source-initiative:{ .lg .middle } __Open Source__
    ---
    The agent is **Apache 2.0** — zero restrictions. The server is 
    **FSL-1.1-ALv2**, fully open for inspection and community contribution.
